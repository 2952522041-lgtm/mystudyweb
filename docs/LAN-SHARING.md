# 局域网共享使用说明

## 主电脑：开启共享

1. 打开页语桌面版，在「课程知识库」左侧的「局域网共享」中点击「开启局域网共享」。
2. 设置至少 6 个字符的访问密码和服务端口（默认 `37891`），再选择 Windows 端权限：PDF 导入、AI 功能，以及高权限的课程管理。课程管理默认关闭；只有明确勾选后才允许创建/删除课程、删除 PDF 和编辑术语表。密码和本次权限只保存在运行中的主进程内存中。
3. 从「可供其他电脑访问的地址」中复制一个与 Windows 电脑处于同一网络的地址。多网卡时会列出多个地址，不要使用 `localhost` 或 `127.0.0.1`。
4. 共享期间主电脑必须保持页语运行、联网且不休眠。关闭共享会让已有查看端会话立即失效；退出页语也会停止服务。

第一版只绑定主电脑的局域网端口，不配置公网暴露、路由器端口映射、第三方隧道或云服务。

## Windows：访问资料

1. 在 Windows Chrome 或 Edge 地址栏粘贴主电脑显示的完整地址。
2. 输入访问密码。验证通过后可以查看课程列表、PDF、课程总结/脑图和已有单 PDF 总结/脑图。
3. 在课程的「PDF 资料」页选择一个不超过 128 MiB 的 PDF，可选择生成 PDF 总结、PDF 脑图及合并课程知识。文件保存、内容校验和 AI 整理全部由主电脑执行；查看端不会获得主电脑的 API Key。导入被接受后可继续阅读，AI 整理在主电脑后台进行，稍后点击「刷新」查看结果。
4. PDF 阅读器支持页码跳转、翻页和缩放；总结或脑图中的 PDF 来源按钮会打开对应文档并跳转到页码。
5. PDF 的页码、页内位置、缩放、右栏模式和分栏宽度会在短暂防抖后保存到主电脑；之后从 Windows 或页语桌面端打开同一课程 PDF，都会恢复这份共享进度。来源按钮指定的页码优先，并从该页顶部开始。旧版只有页码/缩放的记录仍可读取。
6. 主电脑开放 AI 权限时，可以直接在阅读器中生成/重新生成当前页译文，按当前页或全文连续答疑，也可以重新生成单 PDF 或课程成果。API Key、模型配置、OCR、检索和对话历史都留在主电脑；浏览器只收取结果。取消生成会中止浏览器请求，并通知主电脑取消对应 AI 任务。
7. 主电脑开放课程管理权限时，可以创建课程、编辑术语表，以及在二次确认后删除 PDF 或课程。删除课程沿用桌面端回收站策略；所有写入仍经过课程存储的版本和事务校验。
8. 主电脑新增或更新资料后，在查看端点击「刷新」即可读取新版本，不需要重启共享服务。退出使用时点击「退出」。

查看端不提供任意文件路径或通用文件写入。每类能力由主电脑开启共享时单独授权，服务端会再次校验权限、密码会话与 CSRF；浏览器隐藏按钮不是权限边界。导入沿用主电脑现有的课程事务和后台 AI 队列；阅读状态保存在工作区 `Settings/shared-reading-state.json`。没有选择生成选项时不会调用 AI。

答疑草稿按课程 PDF、范围和页码保存在当前查看端浏览器中，重开后可继续编辑；它不写入主电脑的对话历史，也不在设备之间同步。中文输入法选词期间 Enter 不发送，上滚查看回答时不会被自动拉回底部，可用「回到最新回答」返回。阅读状态保存带版本检查，避免无条件覆盖另一端的更新。

查看端显示后台整理的排队、运行、暂停、失败和取消状态；暂停/取消不再显示为忙碌。任务中心的暂停、继续、取消和重试由主电脑操作。课程笔记编辑与成果历史比较也在主电脑课程工作台使用，当前共享协议未开放这两类写入/管理入口。

## 协议与连通性

当前使用普通 HTTP，例如 `http://192.168.1.20:37891/share?yeyu-share=1`。登录密码通过会话 Cookie 传递，所有写操作还需要当前会话的 CSRF 令牌；但 HTTP 本身不加密密码、PDF、提问、回答、总结或令牌，它不能描述为 HTTPS，也不适合不可信网络。请只在确认可信的校园网中使用，并避免把地址和密码发给无关人员。跨不可信网络应先使用受控 VPN（例如由你管理的 Tailscale 网络），不要做路由器公网端口映射。

先在两台电脑上确认连接的是同一校园网，再在 Windows PowerShell 执行：

```powershell
Test-NetConnection 192.168.1.20 -Port 37891
```

然后打开浏览器地址。若端口测试失败，检查主电脑系统防火墙是否允许页语对应端口的局域网入站连接，以及校园网是否启用了客户端隔离；校园网可能禁止设备互访。此时应分别记录：页语界面显示「运行中」且本机服务测试正常，说明应用功能正常；Windows 无法连接，说明是网络/防火墙互通问题，不代表应用已经能跨设备访问。

如端口被占用，页语会显示清楚的错误提示，可以换一个 `1024–65535` 的端口后重试。会话默认有效期为 12 小时，并有基础密码尝试限速；服务停止、会话过期或课程被删除时，查看端会收到可理解的提示。

## 当前验证范围

本机自动化覆盖认证、会话、CSRF、细粒度权限、动作结果脱敏、取消转发、停止/重启、端口占用、路径穿越、符号链接逃逸、中文文件名、PDF 校验/导入、翻译/答疑客户端、课程管理入口，以及阅读进度持久化、字段边界、老数据兼容与版本冲突。真实浏览器回归覆盖页内位置、来源跳页优先、分栏/缩放恢复、草稿和 IME 行为。若当前没有 Windows 校园网实机，仍需在真实 Windows Chrome/Edge 完成 `Test-NetConnection`、大 PDF 上传、真实 AI 翻译/答疑、删除二次确认、来源跳页和双向进度恢复验收；自动化不能替代真实网络、防火墙和浏览器验证。

数据保护验收记录（包括备份核验和临时课程目录访问前后文件哈希比对）见 [`docs/LAN-SHARING-DATA-PROTECTION.md`](LAN-SHARING-DATA-PROTECTION.md)。
