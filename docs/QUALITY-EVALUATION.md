# 文档质量检查

`demo/scripts/check-quality.ts` 在本机读取人工标注的案例，检查术语、关键要点的字面覆盖、公式格式和来源页范围。它不联网、不调用模型，也不读取应用设置或自动扫描课程目录。

```sh
cd demo
pnpm quality:check tests/fixtures/quality-example.json
pnpm quality:check /path/to/local-case.json > /path/to/report.json
```

输入格式见示例 JSON：`source.pages` 按真实 PDF 页序排列；`expectations` 由对照原页的人填写，包括术语首选/禁用译法、关键要点的可接受词组、预期 TeX 和页码；`output` 填入待检查的已生成文字及引用页码。原始材料和实际输出建议保留在工作区外的私有目录，不提交仓库。示例明确标为 `synthetic`，不是模型实测。

报告分别列出事实词组命中、术语问题、公式字面匹配、无法解析的定界公式和非法来源数。关键词命中不判断否定、因果或语义；不同但等价的 TeX 可能报未匹配；未定界公式不计入渲染检查，化学式扩展未纳入这个诊断。来源合法仅表示页码存在，不表示该页支持结论。所有报告均保留 `manualReviewRequired: true`，不合成总分。有效输入生成报告即退出 0，有诊断问题也不冒称通过；输入无效则非零退出。

## 2026-10-05 本地真实资料抽查

选取现有 33 页控制系统讲义及其已保存摘要（`glm-4.6v` / `ai-digest-v11`），只读检查第 4、29 页的渲染图和摘要。本轮没有重新调用模型，也没有改写用户文件。PDF 和原始摘要不进入仓库。

| 检查 | 结果 | 人工核验 |
| --- | --- | --- |
| 第 4 页电机模型 | 关键要点未命中，首选术语缺失 | 原页图片有电枢控制直流电机及参数，历史摘要声称未提供具体内容，确认遗漏 |
| 第 29 页线性化适用条件 | 字面命中 | 原页限制为平衡点附近小偏差，摘要保留了这项限制 |
| 第 29 页状态空间公式 | 预期公式字面匹配 | 此单个公式一致；不代表整份文档公式都正确 |
| 被检查输出的定界公式 | 无解析失败 | 不证明原文公式全部收录或数学等价 |
| 摘要章节来源范围 | 未越界 | 不证明每条引用都支持对应内容 |

两项人工标注要点命中 1 项、两项术语中 1 项缺失、一个预期公式命中；这是一例历史产物诊断，不是 DSH、某个模型或本轮修复后的质量排名。

第 4 页原生文字只有标题和页码，去空白后 25 个字符，旧 OCR 门槛为 24，足以触发漏识别。门槛已调整为 40，并验证命中原生文字缓存后仍按当前门槛判断 OCR。该修改修复这个触发条件，尚未重新生成历史摘要；重新生成会使用已配置的视觉服务。文字长度仍是启发式，较长标题和图文混排需要后续结合图片区域评估。

## 后续验收

从不同课程固定选取文字页、图文混排页、扫描页、复杂公式/表格页；在生成前人工列出来源与关键结论。保存模型、提示词版本、模式、缓存状态、耗时和原始输出，先运行此诊断，再逐页核对遗漏、错误结论、公式等价与跨页术语一致性。至少同时保留正例和失败例，避免仅用渲染通过率代表内容质量。
