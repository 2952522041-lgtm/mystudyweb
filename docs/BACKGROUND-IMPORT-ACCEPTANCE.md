# 后台导入行为与验收记录

## 当前实现（2026-10-02）

- PDF 保存与 AI 整理分离，保存后即可阅读。全局「后台任务」显示所属课程、文件、PDF 整理/课程汇总阶段、进展、耗时、执行次数和错误。
- 任务状态包括 `queued`、`running`、`paused`、`failed`、`cancelled`；完成后清除文档的 `processing`，任务中心依据成果状态展示完成。只有排队和运行视为忙碌。
- 排队/运行任务可暂停，暂停任务可继续，失败/取消任务可重试；排队、运行、暂停任务均可取消。提供批量暂停排队、继续暂停及重试失败入口。
- 暂停/取消先持久化控制状态，再中止执行；PDF、已完成单篇成果和有效中间缓存保留。恢复复用仍有效的缓存，不承诺从未完成模型输出的某个 token 继续。失败、暂停和取消不会自动恢复成运行。
- 桌面版使用主进程监督的独立隐藏执行窗口，阅读界面重载不影响后台整理。执行窗口异常最多自动重建 3 次，之后提示重新启动；退出应用仍会中断任务，下次启动从已保存阶段恢复。
- 网页版仍在打开的页面中运行，重新打开并恢复课程目录授权后才能继续。后台控制不提供任意路径、任意命令或额外工具权限；桌面课程写入经过串行锁和版本检查。

当前回归文件包括 `demo/tests/background-task-controls.test.ts`、`background-service.test.ts`、`background-task-center-browser.test.ts`、`background-task-presentation.test.ts` 和 `course-locks.test.ts`；桌面启动冒烟另覆盖主界面重载、后台窗口异常及恢复边界。DSH 调度限制见 [DSH 后台接入](DSH-INTEGRATION.md)。本节描述代码与测试范围，不表示本轮已安装到用户应用或实测了真实 AI 完成时间。

## 2026-09-28 历史验收

以下数量、打包与实机结果只属于当时版本。

### 行为与边界

- PDF 保存与 AI 整理分离；保存完成即可阅读，不要求配置知识库 AI。
- 多文件逐个快速保存，后台先生成单篇成果，再统一汇总课程。
- 单篇与课程汇总分别持久化进度；失败保留 PDF 和已完成成果，通过重试继续对应阶段。
- 关闭应用会中断后台执行，重新启动后恢复未完成任务；失败任务需显式重试。
- MCP 返回保存/排队状态，不把它当作 AI 完成；命令行支持 `import --wait` 等待最终状态。

### 自动验证

- 全套测试：501/501 通过，无跳过。
- 桌面测试：17/17 通过，无跳过。
- TypeScript 检查通过；lint 无错误，仍存在 React/可访问性等警告。
- Linux x64 桌面构建通过，安装包与构建产物的 app.asar SHA-256 一致。
- 测试覆盖批量部分失败、只重试未完成文件、取消、重复文件、无 AI 导入、阅读不等待 AI、后台恢复、过期结果保护、课程阶段重试不重新分析单篇及批量只汇总一次。
