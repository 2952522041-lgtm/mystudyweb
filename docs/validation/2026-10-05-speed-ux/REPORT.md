# 生成速度与桌面阅读体验验收

日期：2026-10-05。版本：0.2.1。性能实现提交：`0bdf44c`；界面及桌面实现提交：`54e889e`；基线：`69be02a`。

## 改动

- 快速模式复用全部通过结构/来源校验的分块章节与要点，最终请求生成概述和脑图；深入模式继续全文综合。快速缓存按策略隔离，正文参与最终检查点身份。非空术语表保留36KB最终输入预算；无术语表的快速文档可用52KB，完整请求仍受64KB限制和有界拆分保护。
- DSH SDK未必逐token通知应用。取消首事件后的“45秒无SDK通知”超时，保留首事件等待、SDK真实网络空闲、总时限和取消回收。
- 调度按课程轮转，完成材料的课程不必等其他课程的所有PDF。新课程ID加入UUID，避免同毫秒创建覆盖。
- 纸白/墨蓝阅读工作台，管理和共享折叠，目录独立滚动，资料行适配窄窗，导入后定位资料页。采用 [Anthropic frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design) 的设计工作流。
- 审阅预览默认收起、独立滚动，操作按钮保持在前；任务中心同时显示运行/失败/待审阅并适应窄屏，从任务入口定位审阅。课程页及导入框直达知识库设置。
- 修复分栏恢复与持续拖动竞态；明确打开成果时显示总结。仅在可见译文面板请求翻译和预取，隐藏、收起、切换面板取消未完成请求，保留完成缓存。
- 脑图按自身容器宽度排版；窄阅读栏中详情移至画布下方。首次显示定位根节点，只滚动画布，缩放、拖动及调整宽度不会重置用户位置。
- 修复课程连续IPC/手动重载交错导致的旧版本回退。桌面启动仅清旧HTTP缓存，静态资源不缓存，防更新后旧脚本使导入失败；保留课程、设置、IndexedDB和认证cookie。

DSH实际承担章节保留纯函数及测试、合成预算参数及回归、紧凑审阅组件及测试、快速模式集成测试和基准工具初版。主Agent审查集成、运行全套，并处理共享状态、协议计时和实际交互中发现的问题；任务目录未包含用户PDF或凭据。

## 质量抽查与边界

本地对照13页内容、4页原始渲染：B包含9组主要主题，126项证据可在可见正文找到；来源范围、关系端点和循环机械检查通过。这不代表语义全部正确。

- 第22页表格有2个用途单元格错配，B和干净A2都存在，且已存在于最终综合前的分块证据。多列原生文字丢列边界后模型重建不可靠；保留正文不等于修正原分析错误。
- 第6页架构图三次都漏掉图内细节，标题/页脚超过40字阈值而未触发OCR。第5和59页分别为章节分隔及结束页。
- 第45页另一张表8行×3列、第44页两条不等式抽查未发现符号或对应错误。
- B脑图15节点、9叶节点，A2为45节点、32叶节点；主题细节较多放在长说明中，导航粒度降低。**不能宣称等质无损提速。** 深入模式保留，但本次没有另做同样本深入模式质量对照。

这些是本轮明确保留的提取/模型质量限制。后续应以几何数据保留表格列边界，并单独识别“正文大图＋少量标题页脚”；不应简单全局提高OCR字数阈值。详见[安全质量审计](ab-xid-quality-safe-audit.json)。
