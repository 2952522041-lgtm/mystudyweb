## 任务二：课程术语表

### 数据与存储

课程目录根部新增 `glossary.json`，桌面与授权浏览器目录使用同一格式。文件是唯一持久化来源；不写 localStorage。阅读器打开文档时取得课程术语表快照；回到课程库修改后重新打开文档生效。临时打开、未归入课程的 PDF 仍使用空术语表。

```json
{
  "schemaVersion": 1,
  "version": 1,
  "entries": [
    { "source": "momentum", "target": "动量", "forbidden": ["冲量"], "note": "力学术语" }
  ]
}
```

`schemaVersion` 是文件格式版本；`version` 是本地编辑修订号，每次保存递增，导入使用本地修订号，不采信导入文件的修订顺序。源词区分大小写以区分 v/V 等符号；可选字段缺省归一为空。文件缺失按空表兼容，损坏文件明确报错，不静默覆盖。

提供 JSON 文件导入/导出，导入先成为草稿，保存才生效。限制：最多 1000 条、512000 字节；源词/译法各 200 字符、最多 20 个禁用译法、备注 1000 字符。拒绝重复源词、目标与禁用译法冲突、无效版本、空源词/目标译法。无新增运行时依赖。

### 注入与缓存

- 页面翻译（含原有批处理、回退路径）、下一页预取、选段翻译使用同一术语注入函数。
- 知识库的分块分析、文档综合、课程综合也注入命中的规则；保留既有知识库生成流程。
- 根据原文/摘要里的源词、目标译法或禁用译法筛选相关条目，序列化为 JSON 数据，备注仅作上下文。命中规则超过 16000 字符明确拒绝；不偷偷丢弃后面的术语。
- 保留既有科学文本保护、YYKEEP 占位符及还原检查；提示词明确公式、变量、上下标、单位的逐字保护优先于术语规则。没有改动 PDF 解析或 OCR。
- SHA-256 指纹覆盖规范化的 schema、修订号和全部条目（含禁用词、备注）。在原缓存键尾部追加 `:g<指纹>`，不重写既有键结构。文档摘要缓存使用同样扩展。
- 从未设置术语表的空表保留旧键；编辑后清空仍有新修订和新指纹，避免重新命中历史译文。页面内存状态键、预取身份、无须提取原文的快捷缓存恢复、课程目录已有译文恢复均校验指纹。
- 既有课程译文记录仅增加可选 `glossaryFingerprint` 元数据，保持旧记录可读、旧身份兼容；用于本地课程缓存的正确性。没有新增或调整远程访问、局域网共享功能，未改 `docs/REMOTE-ACCESS-OPTIONS.md`。
- 新生成译文在本机 IndexedDB 缓存中附带 `sourceParagraphs`，用于段落对齐检查；该原文字段不写入课程译文发布格式。已有摘要/课程成果不会自动重写或自动付费重新生成，需要用户选择重新生成。

### 一致性检查与界面

入口为课程库侧栏「课程术语表」，窄窗口在现有课程操作区显示同一入口；对话框支持新增、查看、逐字段修改、删除、保存、JSON 导入导出与检查。保持现有布局与组件样式。

可按整门课程或单份文档检查：读取本机每文档/页/目标语言的最新缓存译文，以及摘要章节、要点、概念、课程知识节点。基于术语表做确定性规则检查：

1. 译文或知识成果出现登记的禁用译法。
2. 有对齐原文时，源段命中源词，但译文没有指定目标译法。

结果包含文档名、页码、成果种类、段落序号、源术语、期望译法和命中内容；点击可打开 PDF 来源页。UI 展示缓存译文页数/文档总页数、具有对齐原文的页数。未生成、未保存在本机的译文未检查；无原文的旧缓存及知识成果仅检查禁用译法。未登记同义词、词形变化、语义消歧不属于当前规则能力，结果标为“疑似不一致”供复核。

## 人工验收与边界

建议用一份真实论文课程验证术语导入、跨页实际模型译文、修改后重新打开文档、重生成摘要/课程知识，以及大屏/窄窗口的编辑体验。自动化已覆盖 mock 模型和真实 Electron 交互；本轮没有调用真实服务验证模型是否始终遵从术语表。

浏览器端 File System Access 的真实授权流程、导出文件在用户系统中的保存体验仍需人工验收。规则检查不是语义判定；公式保持原样与某条译法冲突时优先保护公式。跨窗口同时编辑术语表的冲突解决尚未实现，避免同时编辑同一课程。
