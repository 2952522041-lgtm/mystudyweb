# 课程体验与 DSH 完善验收

日期：2026-10-05。版本：0.2.0。

## 交付范围

- DSH 请求历史：最近 200 次，模型、任务类别、耗时、固定错误码、有限重试及并发复用标记；不记录正文或凭据。
- 知识整理首次请求在无正文的网络/服务繁忙错误后最多重试一次，总时限不增加；取消、限流、鉴权和已输出内容不重试。
- 课程综合先保存候选，在结构与总结差异预览中接受或保留原成果。候选跨重启保存，陈旧候选和后续任务受保护。共享端生成也进入审阅，CLI/Blackboard 明确报告等待审阅。
- 原生 PDF 文字按指纹、页码、提取版本缓存，16 MiB / 2048 条上限；OCR 输出独立，缓存稀疏页仍判断 OCR。
- 知识点、摘要、笔记和 PDF 文字层统一搜索，定位知识点、笔记行或 PDF 页；全文索引可取消，文字上限 16 MiB，不调用模型。
- 桌面完整课程备份：流式复制、文件数量/容量/路径约束、SHA-256 清单校验；恢复预览后创建新课程，不覆盖原件。当前实际课程目录格式完成往返测试。
- 设置未保存时保护关闭操作；窄窗口课程切换/新建/连接；桌面构建版本与更新命令。
- 离线内容质量诊断及一例真实历史摘要抽查，修正只剩标题的图片正文页漏触发 OCR。详见 [质量评估](../../QUALITY-EVALUATION.md)。

## DSH 执行与主 Agent 审查

按仓库及个人 `dsh-assisted-development` 技能派发 7 个独立任务：设置关闭保护、页面文字缓存、搜索纯函数、DSH 诊断面板、备份文件层、课程审阅转换、质量检查纯函数。执行者使用本机 DSH headless，任务目录仅含所需源码和依赖链接，没有复制用户凭据或课程资料；每次调用限制 10 分钟。

主 Agent 负责存储/IPC/后台调度和 UI 集成，并独立验证产物。审查后修正了缓存淘汰失败及 LRU 持久化、仅保存 PDF 的搜索范围、备份目录与真实 schema 差异、历史 ID 重映射、审阅和新任务竞态，以及质量计数定义。任务正常退出不作为验收替代。

## 边界与安装状态

备份仅桌面版，采用文件夹格式，最多 10 GiB / 10000 文件；不含应用凭据、未保存草稿及工作区外缓存。恢复的排队/运行/审阅任务暂停，候选归档。搜索文字层不会识别图片，OCR 覆盖仍受实际模型和页面内容影响。

抽查使用已有历史摘要，没有新增模型调用；修复了 OCR 判断触发条件，未自动改写用户已有成果，也不宣称模型质量全面达标。此次未测 Windows 安装。

系统安装的预检 `sudo -n true` 返回需要交互认证，无法在当前会话替用户完成系统安装。可在项目 `demo/` 目录执行 `pnpm desktop:update`，输入本机 sudo 口令后完成安装；该命令同时更新主进程/前端、修正已知旧启动入口并校验安装内容。构建产物不冒充已安装版本。
