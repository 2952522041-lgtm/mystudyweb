## 尚未验证及运行限制

- 登录已经过期，所以当前版本未完成真实网站目录扫描、下载与导入的端到端验收。需要用户重新登录后执行一次完整流程。
- 当前为 Codex 定时任务加确定性脚本，不是独立系统守护程序；浏览器下载通知的路径需要执行模型按固定规程传递，未绕过浏览器接口提取 Cookie。
- 没有以真实教学 PPT 测试转换排版。本次不宣称转换质量经过视觉检查；程序为转换件保留 visualReviewRequired，复核完成前不将新转换件自动导入。
- 现有页面适配器面向 Blackboard Original 的 content_listContainer；结构不符时明确报错并等待维护，不让弱模型猜测页面或扩大课程范围。
- AI 内容生成仍使用页语自己的知识库 AI。执行任务的模型不负责生成课件摘要，也不会因执行模型更换而改变筛选与核验规则。

规则和转换模块按 Luna 分工编写，主 Agent 审查了作用域、临时文件生命周期、缓存一致性、重复执行和失败恢复，并统一集成验证。
